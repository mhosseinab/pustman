First beta of Pustman, a native, GPU-accelerated API client built with GPUI.

**This is a beta.** It has passed the automated test suite on Linux and macOS, but no manual release smoke test has been run yet. Expect rough edges.

## What's in it
- Workspaces as plain folders you can share with Git; New Workspace and New Collection forms.
- Menu bar (native on macOS), workspace switcher, quick open (Ctrl/Cmd-P), command palette.
- Collections tree, environments (shared, local and keychain-backed secret values), globals, history.
- HTTP requests with variables, auth helpers, cookies, redirects, TLS settings; response viewer with pretty/raw/hex/preview, headers, cookies, timeline.
- Postman v2.1 collection, environment and globals import; collection export.
- Console with redacted request details.

## Downloads
- **Linux x86_64:** `pustman-v0.1.0-beta.3-linux-x86_64.tar.gz`. Unpack and run `./pustman`. Optional: `scripts/install-desktop-entry.sh ./pustman` adds the launcher entry and icon. Needs the usual desktop libraries (xkbcommon, Wayland or X11, Vulkan, fontconfig, freetype).
- **macOS (Apple silicon):** `pustman-v0.1.0-beta.3-macos-arm64.zip`. The app is ad-hoc signed but **not notarized**, so macOS blocks it the first time: open it once, then allow it in System Settings → Privacy & Security → "Open Anyway". If macOS says the app is "damaged", run `xattr -dr com.apple.quarantine Pustman.app`.

- **Windows x86_64 (experimental):** `pustman-v0.1.0-beta.3-windows-x86_64.zip`. Unzip and run `pustman.exe`. It is **not signed**, so SmartScreen may warn the first time. This is the first Windows build of Pustman and has had no testing on Windows beyond compiling; if it is missing from this release, the Windows build failed.

Packages are attached by the release workflow a few minutes after publishing.
