First beta of Pustman, a native, GPU-accelerated API client built with GPUI.

**This is a beta.** It has passed the automated test suite on Linux and macOS, but no manual release smoke test has been run yet. Expect rough edges.

## What's in it
- Workspaces as plain folders you can share with Git; New Workspace and New Collection forms.
- Menu bar (native on macOS), workspace switcher, quick open (Ctrl/Cmd-P), command palette.
- Collections tree, environments (shared, local and keychain-backed secret values), globals, history.
- HTTP requests with variables, auth helpers, cookies, redirects, TLS settings; response viewer with pretty/raw/hex/preview, headers, cookies, timeline.
- Postman v2.1 collection, environment and globals import; collection export.
- Console with redacted request details.

## Downloads
- **Linux (Debian, Ubuntu and derivatives):** `pustman_0.1.0-beta.6_amd64.deb`. Install with `sudo apt install ./pustman_0.1.0-beta.6_amd64.deb`; Pustman then appears in your launcher. Remove with `sudo apt remove pustman`.
- **Linux x86_64 (any distribution):** `pustman-v0.1.0-beta.6-linux-x86_64.tar.gz`. Unpack and run `./pustman`. Optional: `scripts/install-desktop-entry.sh ./pustman` adds the launcher entry and icon. Needs the usual desktop libraries (xkbcommon, Wayland or X11, Vulkan, fontconfig, freetype).
- **macOS (Apple silicon):** `pustman-v0.1.0-beta.6-macos-arm64.dmg` — signed with a Developer ID and notarized by Apple: open the .dmg and drag Pustman to Applications. (If this release has a `.zip` instead, the build was not notarized: open it once, then allow it in System Settings → Privacy & Security → "Open Anyway".)

- **Windows x86_64:** `pustman-v0.1.0-beta.6-windows-x86_64-setup.exe` installs Pustman for your user (no admin rights), with a Start-menu entry and an uninstaller in Apps & features. A portable `…-windows-x86_64.zip` is attached too. Neither is code-signed yet, so SmartScreen may warn: More info → Run anyway. It builds in CI but has had little testing on Windows.

Packages are attached by the release workflow a few minutes after publishing.
