## Evidence caveats

- Documentation images may depict v10 or v11 even when the surrounding page is latest v12. Use screenshot_sources.json for asset-level provenance.
- First Draft instructions in older tutorials are obsolete entry-point guidance; current Figma documentation routes this work through the Design agent.
- Native prototype wiring and export are not assumed Design-agent capabilities; use manual native wiring or Code Layers/Make for behavior.
- Postman workspace and resource permission layers must be combined according to actual effective access; roles are not one universal flat list.
- Environment-move permissions are not fully consistent across two official pages. Resolve this against the actual target build/plan before implementing the operation.
- All design metrics, priorities, layouts, personas, sample payloads and token choices are project proposals, not measured user-research findings.

## How to use references

Use Postman images to learn tasks and current domain semantics. Use the original blueprints to consider a new hierarchy. Keep those two types of evidence distinct in the Figma file. Study one interaction from another product at a time rather than mixing several unrelated visual systems.
