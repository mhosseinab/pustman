## What shipped
`resolve_file_ref(workspace_root, reference)`:
- A relative reference is joined to the workspace root and canonicalized. It is refused (`Io`) unless it stays under the canonical root. That covers `..` and symlink escapes.
- A missing file returns `FileNotFound` naming the joined path.
- `Io` details never carry the path or the reference, only a fixed subject and `ErrorKind`.

## Findings history

- Round 3 confirmed both fixes.
