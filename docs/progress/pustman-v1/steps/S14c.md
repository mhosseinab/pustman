## What shipped
- `SpillWriter` keeps the first 10 MB (`DEFAULT_SPILL_LIMIT`) of a body in memory. It streams the rest to a 0600 `tempfile` and returns `ResponseBody::Spilled { prefix, file, total_len }`.
- `SpilledFile` shares one `Arc<TempPath>`, so the file is deleted when the last clone drops. `Debug` redacts the path.
- `ReqwestTransport::read_body` reads the body through `bytes_stream()` and the writer, for the final response and for every redirect hop. Redirect, TLS and timing behaviour from S12 is unchanged.

## Reviewer probes (deleted)
- The N / N+1 boundary is correct.
- The file is deleted when a stream is dropped mid-way, when a send is cancelled, and for a redirect hop body.
