## What shipped

- New crate `crates/console`: `ConsoleEntry` (method, URL, status, time, size, level, protocol, raw text; `Debug` hides the raw text) and the `ConsoleStore` GPUI global. The global is a `VecDeque` capped by `console_max_entries` (default 5000, read from settings). It drops the oldest entry first, ignores new entries while paused, can be cleared, and is memory only.
- `console::init` subscribes to settings changes (the `theme::ThemeStore` pattern) and trims the buffer straight away when the cap shrinks.
- `docs/ARCHITECTURE.md`: the `console` row now marks it a GPUI global with no views, since the step mandates the global.
