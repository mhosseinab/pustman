## Decisions (worker; all re-verified sound)
- **`Unsupported(serde_json::Value)` needs a hand-written `Deserialize`** — `#[serde(other)]` is
  unit-variant-only and would discard the payload. `Request`/`Body`/`Auth` buffer to
  `serde_json::Value`, read the discriminator, strip it and `from_value` the rest into the typed
  variant; **anything else — unknown tag, non-object, or a known tag whose fields won't decode —
  becomes `Unsupported(value)` verbatim**, so it never errors and never drops (REQ-MODEL-02).
  `Serialize` mirrors it. Unit shapes match only when the object holds *nothing but* the tag.
- **`flatten` leftovers come back as `serde_json::Map`**, collected into `BTreeMap` for the `extra`
  field — that is what buys deterministic output. Known fields serialize first, `extra` last.
- **Secret suppression**: `Variable` has hand-written `Serialize` (skips `value` when
  `kind == Secret`) and hand-written `Debug` printing `REDACTED`.
- `Method`: 9 RFC 7231 verbs matched **case-sensitively** to canonical variants; anything else must
  be a non-empty RFC 7230 `tchar` token, kept as `Custom`.
- `effective_auth(chain)`: request → folders → collection; `AuthSource` is positional; empty or
  all-`Inherit` → `(EffectiveAuth::None, AuthSource::Default)`.
- `children` is `#[serde(skip)]` — ADR-0001 persists one file per item with the parent's
  `order: Vec<ItemId>` as the link, so inline children would break the format (issue #2).
- `Auth::Inherit` is default and **not written**: absent and `{"type":"inherit"}` mean the same
  thing — the one known shape that canonicalizes rather than byte-round-tripping.
- `#[allow(clippy::large_enum_variant)]` on `Request` (416 B vs 72 B): boxing `Http` would deviate
  from plan §5's shape and tax every construction site.

## Stewardship note (reviewed and answered)
PRD §4 lists Digest/OAuth2/AwsSigV4/Jwt/OAuth1/Ntlm; S2 + plan §5 restrict the typed set to
Inherit|None|Basic|Bearer|ApiKey|Unsupported. **Verified safe to defer**: all six parse to
`Auth::Unsupported(Value)` holding the full original object and re-serialize byte-for-byte
identical; `effective_auth` treats `Unsupported` as a concrete kind so inheritance still resolves.
Typed variants are additive later with no data migration. Caveat: because `Unsupported` is
concrete it *stops* the inheritance walk (correct — the request set that scheme), so M1's send path
needs a "this auth type isn't supported yet" case rather than a silent send.

## Learnings
- `#[serde(other)]` is unit-variant-only → a raw-value fallback needs a hand-written `Deserialize`
  buffering to `Value`.
- `use serde::ser::Serialize` shadows the derive macro — derive from `serde::{Deserialize, Serialize}`,
  traits from `serde::ser`/`serde::de`.
- `#[serde(flatten)]` leftovers return as `serde_json::Map`, not `BTreeMap`; collecting into
  `BTreeMap` is what buys deterministic output.
- Under `clippy -D warnings`, `derivable_impls` and `large_enum_variant` are build failures.
- **A missing `#[cfg(test)] #[path = …] mod tests;` trailer silently disables a whole test file** —
  `pustman-v1-test.sh`'s aggregate `PASS n` will not show it. Reviewers must filter per mandated
  test name (`cargo test -p <crate> <name>`) and confirm each runs.
