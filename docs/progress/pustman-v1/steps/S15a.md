## What shipped
- `CookieJar` wraps `cookie_store` 0.22 and provides per-workspace store, match, list, add, edit, delete and clear.
- The vendored Mozilla Public Suffix List (`assets/public_suffix_list.dat`, MPL-2.0, 2026-11-19). The cycle-2 reviewer confirmed it is byte-identical to upstream.
  - `PUBLIC_SUFFIX_LIST` is a `LazyLock`. A parse failure panics, because it is a build defect; `test_bundled_public_suffix_list_parses` pins that.
  - `Default` uses `CookieStore::new_with_public_suffix`.
- `publicsuffix` 2.3.0 is a workspace dependency. It is the same crate instance that `cookie_store` and `reqwest` use.
