## Decisions (worker, all re-verified sound by review)
- **Workspace path entries for not-yet-existing crates ARE accepted** — cargo lazily resolves unused
  `[workspace.dependencies]`; `cargo metadata`/`check` pass with 19 missing crate dirs. All 20 path
  entries are in, so **root `Cargo.toml` stays a non-hotspot for dependencies**. Caveat: a step must
  create its crate dir in the same commit that first references `x.workspace = true`, or resolution
  fails then.
- **reqwest 0.13.5 renamed feature `rustls-tls` → `rustls`** (verified against upstream v0.13.5
  manifest). Pinned `default-features = false`, features `["rustls","cookies","stream","gzip",
  "brotli","deflate","multipart","json"]`. Note: this also drops `charset` and `system-proxy`;
  `http2` is deferred to M5 (gRPC h2c) per the PRD. If HTTP/2 to API servers is ever wanted, add
  `http2` to that list.
- **ulid 3.0.0**: `Ulid::new()` is gone → `Ulid::generate()`; `serde` is an implicit
  optional-dependency feature (not in the `[features]` table) — `features = ["serde"]` works.
  `ItemId`'s serde is hand-written over `Display`/`FromStr`, proven by the two tests.
- **Lint set implemented exactly as the Goal** (5 clippy denies + `unsafe_code`). `clippy::
  new_without_default` (style group) is fatal under `-D warnings` → `ItemId` got a `Default` impl
  (minimal fix; adopting Zed's `style = allow` would deviate from the Goal and mask the group).
- `Cargo.lock` left untracked by the worker (outside its Edits set) — integrator regenerated it at
  merge via `cargo metadata --format-version 1 >/dev/null` and committed it.
- CI trigger `on: push` + `on: pull_request` unfiltered; cache is first-party `actions/cache@v4`
  keyed on `rust-toolchain.toml` + `Cargo.lock`; toolchain step `rustup toolchain install` (reads
  `rust-toolchain.toml` incl. components). No `license` field (no LICENSE file, `publish = false`).

## Learnings (for later steps)
- Unused `[workspace.dependencies]` entries are declarations only — never resolved or fetched. That
  is what makes "declare everything M0–M2 needs now" viable, and it means **a later step must create
  its crate dir in the same commit that first uses `x.workspace = true`**.
- crates.io's API `features` map omits implicit optional-dependency features; a "missing" feature
  there is not proof — read the crate's `Cargo.toml` in `~/.cargo/registry/src/`.
- ulid 2.0+ renamed `Ulid::new()` → `Ulid::generate()` and moved serde out of the features table.
- `clippy::new_without_default` (style group) is fatal under the verify script's `-D warnings` —
  every `pub fn new()` needs `Default` unless `style = allow` is adopted repo-wide.
- `style_edition = "2024"` wraps at 100 cols; run `cargo fmt --all` before verify (it runs `--check`).
- reqwest 0.13 renamed `rustls-tls` → `rustls`; `default-features = false` also drops `charset` and
  `system-proxy`, not just `http2`.
- `scripts/pustman-v1-test.sh` PASS count is checked against the named tests at review — a filter
  matching nothing or the wrong tests cannot pass.
