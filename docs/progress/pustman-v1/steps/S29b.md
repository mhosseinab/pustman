## Evidence

- **Review 1 HIGH:** `indent_markup` output grew quadratically with nesting depth, so a 90 KB body produced about 900 MB. The fix caps the indent at `MAX_INDENT_DEPTH = 32` and charges every line against a `4 × input` budget before it is pushed. Over budget, the formatter returns `FormatError::TooLarge` and the view falls back to Raw with an inline note.
  - Review 2 probed 10k and 30k unclosed tags: both were refused with no quadratic allocation.
  - With the cap removed, the new test fails.
- **Review 1 MEDIUM:** the crate-root exports were widened. The fix restores them to `pub use body_view::BodyView;` only.
- **Checks:** review 2 saw `scripts/pustman-v1-test.sh response_viewer` → PASS 7, with clippy and fmt clean and TRIPWIRE 0. After the merge, `scripts/pustman-v1-verify.sh` → VERIFY OK.

## What shipped

The Pretty body mode formats JSON and XML/HTML. Formatting runs when the data changes and is cached, never done in `render`. A body that fails to format, or that would format too large, falls back to Raw with an inline note.
