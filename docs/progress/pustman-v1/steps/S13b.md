## What shipped
`request_auth`: effective auth (inherited from the collection, resolved through `{{var}}`) is applied as Basic (via the `base64` crate), Bearer or API key (header or query). An unsupported auth kind reports `Unsupported`. An empty token, API-key value, API-key name, or both Basic fields empty reports `Incomplete` and changes nothing on the request.

## Findings history
Round 1 caught a hand-rolled base64 encoder. That is what led to the AGENTS.md Reuse rule. Later rounds made unsupported or incomplete auth explicit instead of sending silently.
