## What shipped
- `body.rs`: body modes (none, raw, urlencoded, multipart, file) resolved into a `RequestBody`, with auto `Content-Type` and `Content-Length` headers that a user header overrides.
- `reqwest_transport.rs`: multipart and file bodies are encoded onto the wire.
- `pipeline.rs`, `prepare.rs`, `client.rs`: the body is threaded through resolve → prepare → send.
- `request.rs`: a multipart body's `Debug` prints only a field count, never a field name, value or path.

## Decisions
- Field names are treated as secret-bearing in `Debug`, because variable resolution builds names too (PRD §7). The count is all a log line shows.
