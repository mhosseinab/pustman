## What shipped

`pustman::init_with_store` now runs `init_http_client` then `request_editor::init`, after `command_palette`. `init_http_client` does three things:
- calls `gpui_tokio::init`;
- builds an `HttpClient` over `ReqwestTransport`;
- installs it with `request_editor::send::set_http_client`.

`workspace::NewRequest` now opens a request tab in the running app.
