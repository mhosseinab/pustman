## What shipped
- `ContextMenu` (keyboard navigation, emits `Dismissed`) and `VirtualList` are in the prelude.
- `VirtualList::new(id, item_count, row_key, render_row)` wraps `uniform_list`. Each row's element id and debug selector come from the caller's item key, not the row index. The optional `.track_scroll(UniformListScrollHandle)` lets callers scroll to an item.
- A story view renders every component in both themes (`story.rs`).

## Decisions
- `track_scroll` was added in the fix round. A list over history or response lines needs scroll-to-item anyway, and it is what makes the virtualization test discriminating.
