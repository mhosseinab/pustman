## Goal
A pasted cURL command parses into an `HttpRequest`, and any `HttpRequest` renders as a cURL command
that round-trips.

```
$ scripts/pustman-v1-test.sh api_model curl      → PASS 7
$ scripts/pustman-v1-verify.sh | tail -1          → VERIFY OK
$ scripts/pustman-v1-tripwire.sh                  → TRIPWIRE 0
```
Seven mandated tests present and unweakened. Reports: `/tmp/opencode/pustman-v1-reports/S10-build.md`,
`S10-review.md`.

## What shipped
`api_model::curl` — `parse_curl(&str) -> Result<HttpRequest, CurlError>` using `shlex`, and
`to_curl(&HttpRequest) -> String` with POSIX single-quote escaping. Handles `-X/--request`, `-H`,
`-d/--data/--data-raw/--data-binary/--data-urlencode`, `-F`, `-u` (→ `Auth::Basic`), `-b` (→ `Cookie`
header), `-k` (→ `settings.verify_tls = Some(false)`), `-L`, `--compressed`, and line continuations
`\` and `^` (quote-aware). Unknown flags are **reported** (`CurlError::UnsupportedFlag` / warnings),
never silently dropped.

## Learnings
- The single-phase protocol works. S9's implement (same shape, same crate, same Verify style)
  returned empty three times under the old "one run does the whole loop" protocol; S10's BUILD and
  REVIEW both landed first-try. Each run being small and bounded is what makes it survive.

## Deferred
`--compressed` is parked in `settings.extra["compressed"]` rather than a typed field. The
round-trip is proven for the shapes the seven tests cover; exotic quoting (nested single quotes,
newlines inside values) is not separately pinned.
