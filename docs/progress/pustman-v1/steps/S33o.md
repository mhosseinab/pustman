## What shipped
- `history_list.rs`: re-reads on every `ConsoleStore` change, so a recorded send appears without reopening the panel (#205). `history_panel` → `console` is a UI→UI dependency.
- `http_engine/src/client.rs`: when a cancelled send has a history row, `SendEvent::Cancelled` is emitted from a spawned task after the row is stored. With no recorder it is still emitted synchronously.
- `timeline.rs`: the root is its own scroll container (`id`, `min_h_0`, `overflow_y_scroll`) (#202). It has a focus handle, `key_context("TimelineTab")` and a `ScrollHandle`. Up/Down, PageUp/PageDown and Home/End scroll it, clamped. Tab/Shift-Tab reveal the hop row they land on. Keys with modifiers (other than Shift on Tab) pass through to keybindings such as Ctrl/Cmd-Tab.
- `crates/pustman/Cargo.toml`: unused `url` dev-dep dropped.
- Already on main before this merge: NewTab opens a request (`93a5e04`), console row heights (`c4be074`).

## Decisions
- The review-1 HIGH was a Verify filter the driver wrote wrong in the regenerated brief. The test module was renamed to `timeline_m1_fixes_tests` so the filter matches; no test was weakened.
- The edit set was extended to `http_engine/src/client.rs` for the cancelled-row race that the live refresh exposed.
- Keyboard scrolling uses `on_key_down`, following `response_split.rs`, with no keymap JSON changes; the `TimelineTab` context is ready for a later keymap.
- A late `Cancelled` from a replaced send only changes Console line order (#270). No view state is keyed on it.
