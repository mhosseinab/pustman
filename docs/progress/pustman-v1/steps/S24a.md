## What shipped
- A new `command_palette` crate:
  - a generic `Picker<D: PickerDelegate>`: a query field, a virtualized match list, wrap-around selection that scrolls with the arrow keys, and Confirm/Cancel;
  - a fuzzy scorer in `fuzzy.rs`.
- `confirm_selection` is the one gate for every confirm path: Enter, the `Confirm` action and a click. On an empty match list it does nothing.
- `select_match` is the one selection path. It also scrolls to the reset top match after the query changes.

## Decisions
- A click confirms through the same gate. A row is only clickable when it is rendered, so click behaviour does not change.
- `picker_empty_tests.rs` has its own small probe delegate, because `picker_tests.rs`'s delegate is private and that file is read-only.
