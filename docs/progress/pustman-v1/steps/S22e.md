## What shipped
- `crates/pustman`: a library (`src/pustman.rs`) and a binary (`src/main.rs`).
  - Init order: `settings → theme → ui → keymap → storage → workspace`, one line per crate.
  - The local store at `config_dir()/pustman.db` is opened and migrated in the background, then installed as the global `AppStore`. If it fails, the app falls back to an in-memory store and shows an error toast.
  - `StartupProblems` queues settings, theme, keymap and store problems, and shows them as error toasts once the workspace window exists.
- `main.rs` opens a 1280×800 window titled "Pustman", quits when the window closes, and prints the first-frame startup trace when `PUSTMAN_STARTUP_TRACE=1`.
- Test `wire_shell_init_opens_workspace_with_docks` (`tests/wire_shell.rs`).

## Decisions
- All keymap problems are joined into one toast.
- If the window fails to open, the app writes to stderr and exits with code 1, because there is no window to show a toast in.
- The startup trace was measured on Wayland, but nobody looked at the window. The visual check is left for the S22 E2E display scenario (human, S25).
