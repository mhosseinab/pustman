## Goal

detection, a depth limit of 10, spans for highlighting, and secrets-used tracking.

## Decisions (worker; reviewer judged both sound and minimal)
- **`resolve` returns `Result<Resolved, ResolveError>`** — the step's `-> Resolved` shorthand cannot
  carry `Cycle`/`TooDeep`, which the same step mandates (REQ-VAR-06).
- **`spans(template, &ScopeStack)` takes the scope stack** — `SpanState::{Resolved,Unresolved,Secret}`
  is only knowable against scopes, and the mandated test exercises exactly that.
- **Precedence** is exactly request-local → data → environment → collection → global. `ScopeKind::Data`
  exists as a resolver slot but is never pushed in v1 (no runner), so observable precedence is
  request-local → environment → collection → global. `ScopeStack::push` inserts at the precedence
  position, so narrowest-wins holds regardless of push order (the test pushes widest-first on purpose).
- **Dynamic values** memoize per `DynamicValues` (`$guid`, `$timestamp`, `$isoTimestamp`,
  `$randomInt`, `$randomUUID`); one instance = one send, a fresh send regenerates. `$isoTimestamp`
  is built from `time` components as `YYYY-MM-DDTHH:mm:ss.sssZ` (Postman's shape, provably
  infallible) instead of `format(&Rfc3339)`, which returns `Result`. `$randomInt` is `0..=1000`
  inclusive (Postman/lodash).
- **SECURITY — a Secret never reads `Variable::value` (the file), only `local_values`** (REQ-VAR-SHARE-01/02).
  Structurally true: `value_of` returns `None` for a secret without a local value. An unset secret
  stays literal `{{name}}`, is listed in `unresolved` (never an empty string on the wire) and is NOT
  in `secrets_used` (only substituted secrets are). `Resolved::Debug` redacts `text` when
  `secrets_used` is non-empty; `Binding::Debug` prints `REDACTED`; `ScopeStack::Debug` prints
  `local_values` keys only.
- **Depth** counts nested substitutions: `MAX_DEPTH = 10`, the eleventh → `TooDeep`.
  `Cycle(Vec<String>)` is the chain as entered with the first name repeated.

## Learnings
- thiserror 2.x accepts expressions on `.0` in `#[error(...)]` args (`{}` + `.0.join(" -> ")`) and
  bare consts as positional args (`MAX_DEPTH`) — both compile under `-D warnings`.
- A helper returning `Option<&str>` from either `&self` or a `&Variable` argument needs an explicit
  shared lifetime; elision ties the output to `&self` and rejects `variable.value.as_deref()`.
- rand 0.10.4 exposes `rand::random_range(range)` at the crate root behind the default `thread_rng`
  feature (verified in the pinned vendored source, not memory); uuid's `v4 = ["rng"]` pulls
  `getrandom` into `Cargo.lock` the first time a crate actually uses `uuid`.
- `clippy::manual_contains`/`map_entry` are on by default under `-D warnings`: comparing
  `listed.as_str() == name` and using `contains_key`+`insert`+re-`get` stayed clean as written.
