## What shipped
`crates/http_engine`: `Transport` trait, `FakeTransport` (scripted responses/errors/delays on GPUI
executor timers), `HttpClient` GPUI entity with `pending_send: Option<Task<…>>` where a second send
cancels the first, `SendEvent::Cancelled`, and `TransportError` as the exact PRD §8.6 taxonomy
(`InvalidUrl`, `Dns`, `Connect`, `Tls`, `Timeout`, `TooManyRedirects{chain}`, `Proxy`, `Protocol`,
`Io`, `FileNotFound`, `UnresolvedSecret{names}`, `Cancelled`) each with `user_message()` and
`suggested_fix()`. 4xx/5xx are `Ok(Response)`, never errors.

## Findings history — two redaction gaps the first review caught
1. **`cargo fmt` was not clean at the build commit** although the build report claimed it was. The
   gate is the command's exit code, not the report.
2. **`redacted_url` stripped query and fragment but kept URL userinfo**, so
   `https://user:pass@host/x` Debug-printed the credentials via `ResolvedRequest` and `RedirectHop`.
   Same leak class the crate deliberately prevented elsewhere.
3. **`TransportError` derived `Debug` while carrying raw resolved text** in `InvalidUrl{url}`,
   `Dns{host}`, `Connect{address}`, `FileNotFound{path}` — `.log_err()` formats via `Debug` and
   leaked resolved secrets (PRD §7) that the rest of the crate redacts.

Fix `5b90ef6`: `redacted_url` now clears username and password too; `Debug` for `TransportError` is
hand-written with those four fields redacted while `Display`/`user_message()`/`suggested_fix()` keep
the real text for the UI. Confirm review probed both fixes away and watched their tests fail.

## Learnings
- A build report claiming `fmt clean` is not evidence. Re-run the gate — this one was false and the
  reviewer's exit-code check caught it.
- Redaction must cover every Debug-reachable surface, not just the ones someone remembered. Query
  and fragment were handled; userinfo was not, and it carries credentials exactly the same way.
- `#[derive(Debug)]` on an error type that holds resolved input is a leak by construction. When the
  error carries user data, hand-write `Debug`.
