## What shipped
- `send.rs`: Send goes through `http_engine::send_request` with the editor's `self.scopes`, so auth, secrets and history now apply. `record_outcome` and `record_error` write every send to the Console. A cancelled send records nothing extra.
- `unresolved_warning.rs`, `variable_highlight.rs`, `variable_hover.rs`: the pre-send check, highlighting and hover all resolve against the same scopes that Send uses.
- `curl_paste.rs`: scopes are pushed again after a cURL paste.
- `send_pipeline_tests.rs`: 5 tests.

## Decisions
- `scopes_for_send` copies the scope stack locally. This duplicates prepare's private copy (#197).
- The pre-send check can't see keychain secrets. This has no effect in M1, but S43w must handle it (#198).
- The M1 app has no variable source until S41/S43. The `{{base}}` environment check at S38 is proven only by this step's test; S43w wires the active environment into editors.
