## What shipped
- `toast_layer.rs`: `Workspace::show_toast` and `dismiss_toast` over a `ui::Toasts` stack anchored bottom-right above the status bar. Optional `ToastAction`.
- `modal_layer.rs`: the `ModalView` trait and `ModalLayer` (one modal at a time; opening the same type again toggles it closed). It takes focus and restores it on dismiss. Escape, a click outside, or the view's `DismissEvent` closes it.
- `ui/components/toast.rs`: test selector hooks on the message and the action button.
- `status_bar.rs`: `STATUS_BAR_HEIGHT_PX` is now `pub(crate)` so the toast offset reuses it.

## Decisions
- Error toasts stay until dismissed; other toasts auto-dismiss after `TOAST_DURATION` = 5s.
- Escape is handled by the overlay's `on_key_down`, because no dismiss action exists yet (#74).
- There is no scrim because there is no theme token for one (#75).
- Rebase conflict in `workspace.rs` (S22b's `item` and `pane_tabs` mods): the driver resolved it by keeping both sides.
