## What shipped
- `crates/http_engine/src/history.rs` records history rows for responses, errors and cancellations through the shared `redact_text`. The body window is `HISTORY_BODY_LIMIT` + the longest secret, read from Bytes, File or Spilled bodies on the background task. A secret straddling a cut window is trimmed (straddle-free prefix, incomplete UTF-8 tail dropped) before the 1 MB char-boundary cap.
- `api_model` `redact.rs` gained the prefix helpers. `request_auth.rs` and `prepare.rs` expose the secrets used by a send.

## Decisions
- Whether a body may continue past the window is stated explicitly, not inferred from size. A file whose metadata cannot be read counts as possibly continuing, so the trim still applies (round 3 MEDIUM). The fallback size is used only for the displayed `body_size`.
- A window that holds the whole body keeps its tail, even when it ends like a secret prefix.
